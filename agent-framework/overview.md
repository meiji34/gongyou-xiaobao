## 文件结构

```
agent-framework/
├── overview.md          ← 本文件（框架总览）
├── system-prompt.md     ← Agent 系统 Prompt（角色/风格/边界/转接规则/开场白）
├── workflow-logic.md    ← 工作流逻辑（意图路由/四个分支工作流/安全阈值）
├── data-structures.md   ← 数据结构（工友档案/工单/报修/班车/安全内容）
├── api-spec.md          ← API 接口定义（对话/语音/OCR/记忆/便民工具/转接）
├── law-knowledge-base/  ← 法律知识库（5个md文件，本地检索）
│   ├── 01_保障农民工工资支付条例.md
│   ├── 02_劳动合同法重点条款.md
│   ├── 03_工伤保险条例重点条款.md
│   ├── 04_社会保险法重点条款.md
│   └── 05_高频场景问答手册.md
├── scripts/             ← 核心脚本
│   ├── law_search.py    ← 法律知识库检索（关键词+同义词匹配）
│   └── intent_router.py ← 意图路由器（分类+安全检测+知识库检索）
└── (待建) client/       ← 安卓客户端代码
```

## 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 后端平台 | WorkBuddy（非 Coze） | 法律 Skill 已装在此，可直接调用 |
| 客户端 | WebView 封装 | 复用已有 HTML 原型，1-2天出 MVP |
| 法律能力 | Skill 替代自建 RAG | 2亿+权威数据，免收集/分段/向量化 |
| 记忆方案 | 借鉴 shujuku 架构 | 结构化存储 + 上下文注入 + 自动摘要 |
| 语音方案 | ASR+TTS 插件 | 工友群体打字门槛高，语音是核心交互 |
