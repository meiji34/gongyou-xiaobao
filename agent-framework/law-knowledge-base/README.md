## 导入 Coze 知识库方法

### 方式一：直接上传文件
1. 打开 Coze → 你的 Bot → 知识库
2. 点击"添加知识" → 上传文件
3. 把5个 .md 文件全部上传
4. 分段策略建议：选择"自动分段"或"按段落分段"，分段长度 500-800 字

### 方式二：粘贴文本
1. 打开每个 .md 文件，复制全文
2. 在 Coze 知识库中新建"文本知识"
3. 粘贴内容，保存

## 分段建议

每个法规文件按 "---" 分隔符自然分段，每段 = 一个条款 + 通俗解释，适合作为独立检索单元。

## 检索测试建议

导入后用以下问题测试检索效果：
1. "老板欠我三个月工资怎么办"
2. "没签劳动合同能要双倍工资吗"
3. "工地受伤了怎么认定工伤"
4. "被辞退了有没有补偿"
5. "包工头跑了找谁要钱"
6. "加班费怎么算"
7. "单位不交社保怎么办"
7. "试用期被辞退了"
8. "身份证被老板扣了"
9. "夏天高温有没有补贴"

如果检索结果不理想，可以调整 Coze 知识库的分段策略或相似度阈值。
