# 工友高频场景问答手册

> **说明**：本手册覆盖建筑工友最常遇到的15个权益问题，每个场景按"问题→法律依据→操作步骤→证据清单→提醒"结构整理，供AI检索引用。

---

## 场景1：老板拖欠工资怎么办

**工友问法：** "老板欠我三个月工资了""包工头一直不给钱""工程完了工资还没结"

### 法律怎么说
- 《保障农民工工资支付条例》第三条：任何单位不得拖欠农民工工资
- 《劳动法》第五十条：工资应当以货币形式按月支付给劳动者本人，不得克扣或者无故拖欠
- 拖欠工资被责令后逾期不付的，加付50%~100%赔偿金

### 怎么做
1. **找总包单位协调**：不管你跟的是分包还是包工头，总包有监督责任，直接找项目总包反映
2. **打12333投诉**：向项目所在地劳动监察大队投诉，可以电话也可以现场
3. **申请劳动仲裁**：到当地劳动仲裁委申请，仲裁不收费，时效1年
4. **法院起诉/支付令**：仲裁不服可起诉；也可以直接向法院申请支付令

### 证据清单
- 考勤记录（打卡/工时单/工友证言）
- 工资条、银行流水、微信收款记录
- 跟老板要钱的聊天记录、通话录音
- 包工头欠条（有的话）
- 工牌、出入证（证明劳动关系）

### 提醒
- 仲裁时效1年，从该拿钱没拿到那天起算
- 包工头跑路了找总包，总包有先行清偿责任
- "工程款没到"不是拖欠工资的合法理由
- 不要签"自愿缓发工资协议"，签了也无效

## 场景2：没签劳动合同怎么办

**工友问法：** "干活没签合同""老板不跟我签合同""没有合同能要工资吗"

### 法律怎么说
- 《劳动合同法》第十条：建立劳动关系应当订立书面合同，超过一个月未签的违法
- 《劳动合同法》第八十二条：超过一个月不满一年未签书面合同，每月支付双倍工资
- 满一年未签视为已订立无固定期限合同

### 怎么做
1. **继续干活同时收集证据**：证明你在那干活了
2. **要求补签合同**：书面要求单位签订劳动合同
3. **主张双倍工资**：从第2个月到第12个月，可主张双倍工资差额
4. **申请劳动仲裁**：单位不给的，申请仲裁

### 证据清单
- 工资转账记录、工资条
- 工牌、出入证、工服
- 考勤记录
- 工友证言
- 工作现场照片/视频
- 跟老板/管理的工作微信聊天记录

### 提醒
- 没签合同不影响要工资、要工伤赔偿、要加班费
- 关键是证明"事实劳动关系"
- 双倍工资最多主张11个月（第2-12个月）

## 场景3：工伤怎么赔

**工友问法：** "工地受伤了怎么办""工伤能赔多少""老板不认工伤"

### 法律怎么说
- 《工伤保险条例》第十四条：工作时间工作场所因工作原因受伤算工伤
- 单位应30天内申请工伤认定，单位不申请的工友1年内可自行申请
- 伤残等级不同赔偿不同：十级7个月工资，一级27个月工资
- 单位没交工伤保险的，单位全额赔偿

### 怎么做
1. **先就医**：紧急就近送医，非紧急去工伤保险定点医院
2. **申请工伤认定**：单位30天内申请，不申请的本人1年内去人社局申请
3. **劳动能力鉴定**：伤情稳定后申请鉴定，确定伤残等级
4. **计算赔偿**：按等级对照标准计算
5. **协商/仲裁**：单位不赔的申请劳动仲裁

### 证据清单
- 事故现场照片/视频
- 工友证言
- 医院诊断证明、病历、检查报告
- 医疗费发票
- 劳动关系证明（合同/工牌/工资记录）

### 提醒
- 千万不要被老板"私了"，先做伤残鉴定再谈赔偿
- 没交工伤保险不影响赔偿，只是钱由单位出
- 1年时效别错过，单位不申请自己一定要去

## 场景4：被辞退/被清退有没有补偿

**工友问法：** "老板让我走人""突然被清退了""合同没到期被辞退"

### 法律怎么说
- 合法解除：单位给经济补偿金（N），干满1年补1个月工资
- 违法解除：单位给赔偿金（2N），双倍经济补偿
- 协商解除（单位提出）：给经济补偿金（N）
- 工友主动辞职：一般无补偿（因单位拖欠工资等被迫辞职除外）

### 怎么做
1. **判断是否合法**：有没有合法理由？有没有提前30天通知？
2. **不要签"自愿离职"**：签了就没补偿了
3. **保留辞退证据**：辞退通知、微信聊天、通话录音
4. **申请劳动仲裁**：1年内申请

### 证据清单
- 辞退通知/微信通知
- 劳动合同（有的话）
- 工资记录（算补偿基数）
- 考勤记录（算工作年限）

### 提醒
- 老板口头说"你明天不用来了"也算辞退，要录音留证
- 补偿金按离职前12个月平均工资算
- 干满6个月按1年算，不满6个月补半个月

## 场景5：加班费怎么算

**工友问法：** "加班不给加班费""天天加班没有加班费"

### 法律怎么说
- 《劳动法》第四十四条：
  - 平时延长工作时间 → 不低于工资150%
  - 休息日加班不能补休的 → 不低于工资200%
  - 法定节假日加班 → 不低于工资300%
- 《劳动合同法》第三十一条：不得强迫加班

### 怎么做
1. **记录加班时间**：考勤记录、打卡记录
2. **计算加班费**：按上述倍数乘以小时工资
3. **跟单位协商**：要求支付加班费
4. **劳动监察投诉/仲裁**：协商不成的投诉或仲裁

### 证据清单
- 考勤记录/打卡记录
- 加班通知/排班表
- 工友证言
- 工资条（看有没有加班费一栏）

### 提醒
- 建筑行业很多是计件/包工，加班费计算方式可能不同，具体看合同约定
- 法定节假日加班不能用补休代替，必须付300%加班费
- 休息日加班可以先安排补休，不能补休的付200%

## 场景6：没缴社保怎么办

**工友问法：** "老板没给我交社保""单位说不交社保多发点钱"

### 法律怎么说
- 《社会保险法》第五十八条：单位30天内办社保登记
- 五险必须全部缴纳，不能选择性缴纳
- 不交社保违法，可责令补缴+滞纳金+罚款
- "自愿放弃社保"协议无效

### 怎么做
1. **跟单位协商**：要求依法缴纳社保
2. **打12333投诉**：向社保经办机构投诉
3. **劳动仲裁**：劳动关系有争议的先确认劳动关系

### 证据清单
- 劳动关系证明
- 工资记录（看有没有社保扣款）
- 跟单位沟通社保的记录

### 提醒
- 社保不能以现金替代，"把社保钱发给你"是违法的
- 工伤保险单位必须交，工友不掏钱
- 换城市社保可以转移

## 场景7：包工头跑路了找谁要钱

**工友问法：** "包工头跑了""分包老板跑路了工资找谁要"

### 法律怎么说
- 《保障农民工工资支付条例》第二十九条：分包拖欠的，总包先行清偿
- 第三十六条：发包给无资质个人的，由建设单位或总包清偿
- 总包有工资保证金，可以用来支付拖欠工资

### 怎么做
1. **找总包单位**：总包有先行清偿责任，直接找总包要
2. **找建设单位（甲方）**：总包也推诿的，找甲方
3. **打12333投诉**：劳动监察介入，可以动用工资保证金
4. **申请劳动仲裁**：同时仲裁分包和总包

### 证据清单
- 在项目干活的证明（考勤、工友证言）
- 包工头欠条/欠薪承诺
- 跟包工头的沟通记录
- 项目名称、总包单位名称

### 提醒
- 就算包工头跑了，总包跑不了
- 记住总包单位名称和建设单位名称，投诉时要用
- 工资保证金就是防这种情况的，劳动监察可以动用

## 场景8：合同到期不续签有没有补偿

**工友问法：** "合同到期了老板说不续签""合同到期不干了有赔偿吗"

### 法律怎么说
- 《劳动合同法》第四十六条：合同到期终止，单位不续签或降低条件续签工友不同意的，单位给经济补偿金（N）
- 如果单位维持或提高条件续签，工友自己不签的，没有补偿

### 怎么做
1. **确认续签条件**：单位是不续签，还是降低条件续签？
2. **保留通知证据**：单位不续签的通知、微信聊天
3. **要求经济补偿**：干满1年补1个月工资
4. **不给的仲裁**：1年内申请劳动仲裁

### 证据清单
- 劳动合同
- 单位不续签/续签条件的通知
- 工资记录

### 提醒
- 合同到期单位不续签 ≠ 白走人，有经济补偿
- 但如果单位给同样或更好的条件你不愿意签，就没有补偿
- 连续签两次固定期限合同后，第三次应签无固定期限合同

## 场景9：试用期被辞退怎么办

**工友问法：** "试用期被辞了""试用期老板说不要我了"

### 法律怎么说
- 《劳动合同法》第二十一条：试用期解除合同，单位需证明不符合录用条件
- 《劳动合同法》第三十九条：劳动者不符合录用条件的，单位可以解除
- 单位需举证"不符合录用条件"，不能口头说不要就不要

### 怎么做
1. **要求单位说明理由**：必须有证据证明你不符合录用条件
2. **保留辞退证据**：辞退通知、微信聊天
3. **申请劳动仲裁**：单位举证不了的，属于违法解除，可要2N赔偿

### 证据清单
- 辞退通知/微信聊天
- 试用期合同
- 录用条件说明（有的话）

### 提醒
- 试用期不是"随便辞退期"，单位必须有理由有证据
- 试用期工资不能低于转正工资的80%
- 试用期长度有法定上限（合同1年内试用期最多1个月）

## 场景10：工资低于最低工资标准

**工友问法：** "工资太低了""不到最低工资标准"

### 法律怎么说
- 《劳动法》第四十八条：国家实行最低工资保障制度，单位支付的工资不得低于当地最低工资标准
- 最低工资标准各地不同，由省级政府公布

### 怎么做
1. **查当地最低工资标准**：打12333问或查当地人社局网站
2. **对比自己工资**：如果低于标准，要求单位补足
3. **打12333投诉**：劳动监察责令补足
4. **劳动仲裁**：投诉不解决的申请仲裁

### 证据清单
- 工资条/银行流水
- 考勤记录
- 劳动合同（约定工资）

### 提醒
- 最低工资是应发工资扣除社保/公积金前的标准
- 计件工资折算后也不能低于最低工资
- 试用期工资不得低于最低工资标准

## 场景11：被扣工资/罚款怎么办

**工友问法：** "老板扣我工资""工地罚款合法吗"

### 法律怎么说
- 《劳动法》第五十条：不得克扣劳动者工资
- 单位无权对工友"罚款"，罚款权属于行政机关
- 可以扣工资的情形：代扣个税、社保、法院判决执行等法定情形
- 因工友原因造成损失的，每月扣除不得超过当月工资20%，且不低于最低工资

### 怎么做
1. **确认扣款理由**：是否属于法定可扣情形
2. **要求书面说明**：单位应书面说明扣款原因和金额
3. **打12333投诉**：违法克扣的投诉
4. **劳动仲裁**：要回被扣工资

### 证据清单
- 工资条（看扣款明细）
- 扣款通知/微信聊天
- 考勤记录

### 提醒
- 老板说"迟到罚款100"这种是违法的，单位没有罚款权
- 因为损坏工具扣工资，每月最多扣20%，且扣完不能低于最低工资

## 场景12：身份证被扣押怎么办

**工友问法：** "老板扣我身份证""入职要押身份证"

### 法律怎么说
- 《劳动合同法》第九条：用人单位招用劳动者，不得扣押劳动者的居民身份证和其他证件
- 第八十四条：扣押身份证的，由劳动行政部门责令退还，并处罚款

### 怎么做
1. **要求退还**：直接要求单位退还身份证
2. **打12333投诉**：劳动监察责令退还
3. **报警**：情况严重的可以报警

### 提醒
- 任何单位都无权扣押你的身份证
- 入职可以让单位复印留存，但不能扣押原件
- 同理，不能收取押金、培训费等

## 场景13：高温作业有没有补贴

**工友问法：** "夏天工地干活有没有高温补贴""高温费怎么发"

### 法律怎么说
- 《防暑降温措施管理办法》：日最高气温达到40℃以上应停止室外作业；37℃以上40℃以下全天室外作业不超过5小时
- 高温津贴标准由各省制定，一般在每年6-9月发放
- 高温津贴不得以清凉饮料充抵

### 怎么做
1. **查当地高温津贴标准**：问12333或查人社局网站
2. **要求单位发放**：在岗且从事高温作业的应发高温津贴
3. **投诉**：不发的向劳动监察投诉

### 提醒
- 高温津贴是钱，不是绿豆汤
- 室外35℃以上就要发高温津贴
- 不得以清凉饮料充抵高温津贴

## 场景14：女工友特殊权益

**工友问法：** "怀孕了能不能继续干""产假有多少天"

### 法律怎么说
- 《劳动法》/《女职工劳动保护特别规定》：
  - 不得因怀孕/生育/哺乳降低工资、辞退、解除合同
  - 产假不少于98天（各地有延长，多数省份128-158天）
  - 产前检查时间算工作时间
  - 哺乳期每天1小时哺乳时间

### 怎么做
1. **通知单位**：书面通知单位怀孕情况
2. **保留证据**：医院检查记录
3. **维权**：因怀孕被辞退/降薪的，申请劳动仲裁

### 提醒
- 怀孕期间单位不能辞退你（除非严重违规违纪）
- 产假期间有生育津贴（交了生育保险的由基金出）
- 不得安排孕妇从事高强度/高空/低温等作业

## 场景15：劳动仲裁怎么申请

**工友问法：** "仲裁怎么弄""去哪里申请仲裁""仲裁要多少钱"

### 法律怎么说
- 《劳动争议调解仲裁法》：劳动仲裁不收费
- 仲裁时效1年，从知道权益被侵害之日起算
- 追索劳动报酬的，不受1年限制（但劳动关系终止后1年内要申请）

### 怎么做
1. **准备材料**：
   - 仲裁申请书（网上有模板）
   - 身份证复印件
   - 证据材料（合同、工资记录、考勤等）
2. **去哪里申请**：用人单位所在地或劳动合同履行地的劳动仲裁委
3. **提交申请**：现场提交或网上申请（部分地区支持）
4. **等受理通知**：5天内决定是否受理
5. **开庭**：受理后开庭审理，45天内出裁决（复杂可延15天）

### 证据清单
- 仲裁申请书
- 身份证
- 劳动关系证明
- 权益受损证据（工资记录、辞退通知等）
- 其他相关证据

### 提醒
- 仲裁不花钱，不要被"请律师花钱"吓住
- 符合法律援助条件的可以申请免费律师（打12348）
- 仲裁裁决不服的15天内可以起诉到法院
- 劳动报酬争议，工友可以选择不经过仲裁直接去法院申请支付令
